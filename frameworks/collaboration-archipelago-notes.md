# Designing how we work together

Source deck created 19 August 2026. Final assets are kept as `collaboration-spectrum-slides.pdf` and `collaboration-spectrum-slides.pptx` when published.

Core model: Connect, Coordinate, Cooperate, Collaborate, Commons. These are modes, not stages. Cross-cutting design choices: openness, where control sits, contribution and reciprocity, governance/infrastructure, and change/exit.
